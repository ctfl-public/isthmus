# Verification: Flux Mapping Conservation

This case provides a verification of scalar conservation for a simple geometry using ISTHMUS. In general, the flux mapping procedures of marching windows should conserve the total of whatever scalar value is being mapped from the triangle surface mesh to the voxel domain (assuming no triangle is left unmatched to at least one voxel).

By running the fluxMapping.py script in this folder, a user can test this conservation for a cubic geometry. At the top of the script, the user specifies a voxel size, a grid cell size, and an angle with which to rotate the cube around the z-axis. Given these parameters, a voxelized solid will be generated by the script and fed to ISTHMUS to create a surface and map it to the surface voxels.

Next, a scalar value is applied to each triangle proportional to its area. The flux mapping triangle-voxel matching is used to map the triangle scalars to the matched voxels. By summing the total scalar value across all triangles and comparing that to the summed scalar value across all voxels post-mapping, conservation can be verified. Percent conservation error is printed to the console.
